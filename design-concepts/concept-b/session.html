AI summary

This host runs a public-facing API gateway with several soft spots. An unauthenticated Redis instance on port 6379 allows arbitrary key read/write and, combined with its default configuration, a plausible path to remote code execution. The SSH daemon reports an OpenSSH 7.2 banner, which corresponds to a known authentication bypass window. Subdomain enumeration also surfaced staging.northwind-corp.io, a CNAME still pointing at a deprovisioned cloud load balancer — a classic subdomain takeover setup. TLS termination accepts TLS 1.0 alongside modern versions, and the web server discloses its internal framework version in response headers. Recommend prioritizing the Redis exposure and SSH upgrade before anything else on this host.

Suggested exploit paths

Redis unauthenticated write → cron-based RCE

With write access to Redis, an attacker can use CONFIG SET dir and CONFIG SET dbfilename to redirect the RDB dump into a cron directory, then plant a scheduled job as the dumped key content — a well-documented technique against exposed, unauthenticated Redis instances.

SSH banner-matched auth bypass

The reported OpenSSH version lines up with a publicly disclosed authentication bypass affecting builds from that era. Confirm the exact patch level directly before attempting exploitation — banners can be modified independently of the true patch state.
